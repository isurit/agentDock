# Roadmap

1. Local MVP: Project registration, Task lifecycle, SQLite History/Memory, Mock, local Handoff, Git snapshot, runtime diagnostics and privacy controls.
2. Reliability: browser smoke automation, pagination efficiency, data backup/restore and migration tooling, task deletion/retention, project registration policy.
3. Real adapters: Codex App Server with live synthetic read/edit verification; Claude/Gemini headless adapters with synthetic contract tests. Next: company live validation, native session resume and headless approval bridging.
4. Android workflow: synthetic Android fixture, local Logcat and Gradle artifacts under explicit policies; Android Studio remains the build/run interface.
5. Company Ubuntu validation: OAuth/model capabilities (only if policy permits), OS lifecycle, company source safeguards and distribution policy. Never infer company results from CI.

No dates or company compatibility are promised from synthetic tests alone. Record each provider/OS/CLI verification separately.
